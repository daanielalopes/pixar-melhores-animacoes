# PIXAR - Melhores Animações 🩵

Site de fã dedicado às melhores animações da **Pixar**, desenvolvido com **HTML, CSS e JavaScript**. Reúne os filmes favoritos com seus personagens e cenas marcantes.

## 📋 Sobre

Portal estático que apresenta uma seleção de animações da Pixar. Na página inicial há um destaque, a seção "Mundo Pixar" e a galeria "Melhores animações", onde os cards dos filmes são gerados dinamicamente via JavaScript a partir de uma lista de dados (título, imagem, descrição e link).

Cada filme tem sua própria página de **personagens** e uma seção de **cenas**.

### 🎬 Filmes incluídos

- Monstros S.A.
- Procurando Nemo
- Divertidamente
- Toy Story
- Soul
- Up: Altas Aventuras
- Ratatouille
- Viva: A Vida é uma Festa

## 🗂️ Estrutura

```
.
├── index.html                 # página inicial (destaque + galeria de filmes)
├── script.js                  # dados dos filmes e renderização dos cards
├── style.css                  # estilos da home
├── paginas/
│   ├── personagens/           # uma página por filme, com seus personagens
│   └── cenas/                 # páginas com cenas marcantes dos filmes
└── img/
    ├── home/                  # imagens da home, logos e redes sociais
    ├── filmes/                # capas dos filmes
    └── personagens/           # imagens dos personagens, por filme
```


## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
